# Как работает бегущая строка проектов

В строке все твои репозитории, публичные и закрытые, свежие первыми. Раз в 6 часов
GitHub Actions (workflow **Profile**) сверяет список репозиториев и перерисовывает
картинки, так что новый репозиторий появится в строке сам.

## Один раз: чтобы в строку попадали и закрытые репозитории

Без этого шага в строку сами попадают только новые **публичные** репозитории. Закрытые,
которые уже есть в строке, никуда не денутся.

1. GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** →
   Generate new token.
2. Repository access: **All repositories**. Permissions → Repository → **Metadata: Read-only**.
   Больше ничего не нужно: этим ключом можно только читать список репозиториев.
3. Скопируй ключ, открой репозиторий `atomi7e/atomi7e` → Settings → Secrets and variables →
   Actions → New repository secret. Имя `PROFILE_TOKEN`, значение: ключ.
4. Actions → Profile → **Run workflow**, чтобы обновить сразу.

У закрытого репозитория в строке видны имя и язык. Его описание с GitHub не
показывается: его писали для закрытой страницы. Чтобы описание появилось, задай его
в `projects.json`.

**Важно:** с ключом новый закрытый репозиторий попадёт в строку в течение 6 часов,
и его имя останется в истории этого публичного репозитория навсегда. Если заводишь
закрытый репозиторий, который нельзя показывать даже по имени, сразу после создания
поставь ему тему `hide-from-profile` (см. ниже).

Ключи fine-grained истекают. Когда ключ перестанет работать, Action не упадёт: он
обновит только публичные репозитории и оставит в логе предупреждение. Тогда создай
новый ключ и замени секрет.

## Назвать или описать проект: `projects.json`

Открой файл на GitHub, нажми карандаш и добавь блок в `projects` (ключ — имя репозитория):

```json
"my-new-repo": {
  "name": "My new app",
  "about": "One line about what it does"
}
```

Нажми Commit, через минуту профиль обновится. Без такого блока имя возьмётся из названия
репозитория (`my-new-repo` → «My new repo»), а описание из GitHub (только у публичных).

## Убрать проект из строки

Добавь имя репозитория в список `exclude`. Пустые репозитории и форки строка не
показывает сама.

`projects.json` виден всем. Если закрытый репозиторий нельзя показывать даже по имени,
не пиши его туда: открой сам репозиторий → шестерёнка у About → Topics → добавь тему
`hide-from-profile`. Строка его пропустит, и имя нигде не появится. Тему строка видит
только с ключом `PROFILE_TOKEN`.

Эмодзи и кириллицу в описаниях с GitHub строка пропускает: шрифт профиля их не рисует.
Для русского описания впиши английское в `projects.json`.

## Поменять тексты в шапке и в блоках Now и Stack

Они в начале `build/scenes.py`. После правки GitHub Actions перерисует картинки сам.
